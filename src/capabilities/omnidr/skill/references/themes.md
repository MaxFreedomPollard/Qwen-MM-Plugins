# Report themes

Set `meta.theme` to a theme below and `meta.category` to the subject category.
Themes change colors, display fonts, and corner rounding; layout and interactions
remain the same. All themes support light and dark mode. The default is `t01`.

| id  | name              | vibe / accent            | good for |
|-----|-------------------|--------------------------|----------|
| t01 | Indigo (default)  | balanced indigo+sky      | general, mixed, unknown |
| t02 | Academic          | blue, **serif** display  | lectures, papers, science, education |
| t03 | Emerald           | green, clean             | finance, markets, business, economics |
| t04 | Navy & Gold       | navy+amber, **serif**    | law, policy, government, institutional |
| t05 | Cyan Tech         | cyan, tight radius       | software, gadgets, AI, engineering |
| t06 | Warm Editorial    | orange, **serif**        | long-form essays, documentary, culture |
| t07 | Magazine Red      | red, bold                | news, breaking, sports, hype reveals |
| t08 | Fresh Mint        | mint green               | health, food, lifestyle, wellness |
| t09 | Creative Purple   | violet+magenta, round    | design, art, music, creative reviews |
| t10 | Monochrome        | near-black, minimal      | minimalist, data-heavy, serious analysis |
| t11 | Teal              | teal+cyan                | travel, ocean, environment, geography |
| t12 | Rose              | pink, round              | beauty, fashion, vlog, relationships |
| t13 | Amber News        | amber, **serif**         | history, biography, retrospectives |
| t14 | Forest            | deep green+lime          | nature, outdoors, agriculture, DIY |
| t15 | Crimson           | crimson, **serif**       | film/drama analysis, true-crime, opinion |
| t16 | Ocean             | ocean blue               | science comms, space, docu-explainers |
| t17 | Sunset            | pink→orange, round       | entertainment, gaming, pop culture |
| t18 | Grape             | purple                   | tech-creative crossover, product launches |
| t19 | Steel             | slate+sky, tight         | enterprise, B2B, hardware, industrial |
| t20 | Earth / Sand      | brown+gold, **serif**    | archaeology, food-craft, heritage, rural |
